უწყვეტი პარტნიორი — კონტექსტი, იდენტობა, ინიციატივა.

3 · ლიტერატურა

ხარვეზი, რომელსაც ნაშრომი ავსებს

LLM-მეხსიერების სისტემები

თითოეული ერთ თეორიას ახორციელებს, ფასდება სიზუსტეზე (HippoRAG, MemoryBank, ReadAgent…).

აღქმის კვლევები

მეხსიერება აყალიბებს — და შეუძლია შეარყიოს — ურთიერთობა (Cox, Replika).

ვერ მოიძებნა კონტროლირებადი კვლევა, რომელიც სხვადასხვა თეორიაზე დაფუძნებულ არქიტექტურებს ადარებდეს აღქმულ სოციალურ კონსტრუქტებზე — მით უფრო ხმაში.

4 · თეორიული საფუძველი

ექვსი მეხსიერების თეორია → ქცევითი ნიშანი

  • ატკინსონ-შიფრინი — მრავალსაცავიანი, გამეორება
  • ებინგჰაუზი — დავიწყების მრუდი
  • ტულვინგი — ეპიზოდური / სემანტიკური
  • ბუნდოვანი კვალი — gist vs verbatim
  • CLS — სწრაფი ჰიპოკამპი, ნელი კორტექსი
  • ჰიპოკამპური ინდექსირება — მაჩვენებლები

თითოეულს ვიხილავთ არა როგორც ისტორიას, არამედ იმ დაკვირვებადი ქცევის კუთხით, რომელსაც პროგნოზირებს.

5 · არქიტექტურა

Profile C — მეხსიერების ხუთსაფეხურიანი ციკლი

  1. კოდირება — LLM აფასებს მნიშვნელობას (salience); მნიშვნელოვანი დიდხანს ძლებს.
  2. წარმოდგენა — არსი (gist) + ზუსტი ღუზა (anchor).
  3. დაქვეითება — ებინგჰაუზისეული, დროსთან ერთად ქრება.
  4. კონსოლიდაცია — ოფლაინ „ძილი“: ეპიზოდური → სემანტიკური.
  5. მოძიება — არსზე პრიორიტეტით, სიახლით შეწონილი; გამოყენება აძლიერებს.
5.1 · თეორია → კოდი

კოდირება: ორი თეორია, სამი სტრიქონი

ყურადღება / მნიშვნელოვნებაsalience-gated encoding — ყველაფერი არ ღირს დამახსოვრებად
sals = _salience_batch(events)
S0 = DECAY_S_BASE * max(0.1, sal)
ბუნდოვანი კვალის თეორიაfuzzy-trace — არსი (gist) + ზუსტი ღუზა (anchor)
g, anchor = _gist_anchor(ev)
self.episodes.append({"gist": g, "anchor": anchor, …})

poc/harness.py · MemC.end_session() — რეალური გაშვება: „ამინდი მზიანია“ sal=0.20 → S=0.4 · „მე მქვია ლექსო“ sal=0.90 → S=1.8

5.2 · თეორია → კოდი

დინამიკა: დავიწყება, კონსოლიდაცია, გამყარება

ებინგჰაუზი (1885)დავიწყების მრუდი — R ეცემა, თუ კვალი არ განახლდა

6 · მექანიზმი

მთელი დინამიკა ერთ ფორმულაში

R = exp(−Δt / S)
def _R(self, m, now):
    dt = max(0, now - m["last"])
    return math.exp(-dt / max(0.3, m["S"]))
  • R — მოძიებადობა (0–1) · Δt — გასული დრო · S — სტაბილურობა
  • საწყისი S = 2.0 · მნიშვნელობა · გამყარება S += 0.5 · სემანტიკური S = 5.0
  • დავიწყების ზღვარი 0.10 — რბილი დავიწყება, არა წაშლა
  • ყველა ძვირი ოპერაცია ოფლაინ; მოძიება — ერთი embedding, ნულ LLM-გამოძახება ტურზე

8 · შეფასება

სამი მიმართულება — და გულახდილობა

  • ტექნიკური შეფასება (თავი 4) — მოძიების ხარისხი, ლატენტურობა.

ამ ნაშრომში არცერთი მტკიცება არ ეყრდნობა ადამიანების მონაცემებს — ეს პატიოსნად არის დეკლარირებული.

9 · სტატისტიკური პოზიცია

C > B+ — შეფასების სამიზნე, არა ტესტი

  • C vs B+ ეფექტი კონსტრუქციით მცირეა (dz ≈ 0.28).
  • n ≈ 20-ზე მისი დადასტურება შეუძლებელია (საჭიროა n ≈ 116–159).
  • ამიტომ ის წინასწარ რეგისტრირებული შეფასების სამიზნეა (ეფექტის სიდიდე + 95% CI).
  • ზუსტი ნული — შინაარსობრივი, გამოსაქვეყნებელი შედეგია. სწორედ ამისთვის არსებობს B+.
