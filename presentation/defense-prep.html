გამოყენებული თეორიები

Theories used

ატკინსონ-შიფრინის მრავალსაცავიანი მოდელიAtkinson & Shiffrin, 1968

მეხსიერება სამი საცავია — სენსორული, სამუშაო, გრძელვადიანი; ინფორმაცია თანდათან გადადის ერთიდან მეორეში.

Profile C-ში → სამუშაო ფანჯარა + გრძელვადიან საცავზე გადატანა; salience წყვეტს რა გადავა გრძელვადიანში.

Atkinson–Shiffrin multi-store modelAtkinson & Shiffrin, 1968

Memory is three stores — sensory, working, long-term; information gradually passes from one to the next.

In Profile C → Working window + transfer to the long-term store; salience decides what moves into long-term.

ებინგჰაუსის დავიწყების მრუდიEbbinghaus, 1885

დამახსოვრებული მასალა დროთა განმავლობაში ექსპონენციურად ქრება; გამეორება ანელებს ქრობას.

Profile C-ში → lazy decay R = exp(−Δt/S) + გამყარება (S += 0.5 მოძიებისას).

Ebbinghaus forgetting curveEbbinghaus, 1885

Learned material decays exponentially over time; repetition slows the decay.

In Profile C → Lazy decay R = exp(−Δt/S) + reinforcement (S += 0.5 on retrieval).

ტალვინგის ეპიზოდური / სემანტიკური მეხსიერებაTulving, 1972

გრძელვადიანი მეხსიერება ორ სისტემად იყოფა: ეპიზოდური (მოვლენები) და სემანტიკური (ფაქტები/ცოდნა).

Profile C-ში → ორი ცალკე საცავი; ეპიზოდები კონსოლიდირდება სემანტიკურ ფაქტებად.

Tulving's episodic / semantic memoryTulving, 1972

Long-term memory splits into two systems: episodic (events) and semantic (facts/knowledge).

In Profile C → Two separate stores; episodes consolidate into semantic facts.

ბუნდოვანი კვალის თეორიაReyna & Brainerd, 1995

მეხსიერება პარალელურად ინახავს gist-ს (არსი) და verbatim-ს (ზუსტი); gist უფრო მდგრადია.

Profile C-ში → gist+anchor წარმოდგენა; gist-first მოძიება, verbatim მხოლოდ ზუსტი გახსენებისთვის.

Fuzzy-trace theoryReyna & Brainerd, 1995

Memory keeps gist (essence) and verbatim (exact) in parallel; gist is more durable.

In Profile C → gist+anchor representation; gist-first retrieval, verbatim only for exact recall.

კომპლემენტარული სწავლის სისტემები (CLS)McClelland, McNaughton & O'Reilly, 1995

სწრაფი ჰიპოკამპური სწავლა ავსებს ნელ ნეოკორტიკალურ განზოგადებას; ჰიპოკამპი „ასწავლის“ კორტექსს.

Profile C-ში → episodic→semantic კონსოლიდაცია — განმეორებადი ეპიზოდები აბსტრაჰირდება მდგრად ფაქტად.

Complementary Learning Systems (CLS)McClelland, McNaughton & O'Reilly, 1995

Fast hippocampal learning complements slow neocortical generalization; the hippocampus 'teaches' the cortex.

In Profile C → episodic→semantic consolidation — recurring episodes abstracted into a durable fact.

ჰიპოკამპური ინდექსირების თეორიაTeyler & DiScenna, 1986

ჰიპოკამპი ინახავს „ინდექსს“ — მაჩვენებელს განაწილებულ ნეოკორტიკალურ კვალზე, არა თავად შინაარსს.

Profile C-ში → კონსოლიდაციის back-pointer-ები — სემანტიკური ფაქტი ინარჩუნებს კავშირს წყარო-ეპიზოდებთან.

Hippocampal indexing theoryTeyler & DiScenna, 1986

The hippocampus stores an 'index' — a pointer to distributed neocortical traces, not the content itself.

In Profile C → Consolidation back-pointers — a semantic fact keeps links to its source episodes.

არქიტექტურა მარტივად

Architecture in plain words

Profile C არის სასაუბრო AI-ს მეხსიერების არქიტექტურა, რომელიც ადამიანის მეხსიერების პრინციპებს ბაძავს: ყველაფერს კი არ იმახსოვრებს — მნიშვნელოვანს; დროთა განმავლობაში ივიწყებს, თუ არ გაიმეორა; და განმეორებად დეტალებს განაზოგადებს მომხმარებელზე მდგრად ცოდნად. მიზანი — AI აღიქმებოდეს არა ერთჯერად ხელსაწყოდ (ასისტენტად), არამედ უწყვეტ თანამოსაუბრედ.

Profile C is a memory architecture for conversational AI that mimics principles of human memory: it doesn't store everything — it stores what matters; it forgets over time unless something recurs; and it generalizes recurring details into durable knowledge about the user. The goal — for the AI to be perceived not as a one-off tool (an assistant), but as a continuous interlocutor.

  1. ისმენს და აფასებს მნიშვნელობას — ადამიანივით, ყველაფერს არ იმახსოვრებს: წვრილმანი ქრება, მნიშვნელოვანი (სახელები, ემოციები, ვალდებულებები) რჩება. salience
  2. ინახავს არსს, არა სიტყვასიტყვით — ვიმახსოვრებთ საუბრის აზრს (gist), არა ზუსტ ტექსტს; თუმცა ერთ ზუსტ ციტატას (anchor) ვინახავთ, როცა სიზუსტეა საჭირო.
  3. თანდათან ივიწყებს დროსთან ერთად — კვალი სუსტდება, თუ არ განახლდა; მნიშვნელოვანი — უფრო ნელა. R = exp(−Δt/S)
  4. „ოფლაინ“ ახდენს კონსოლიდაციას — როცა ერთი და იგივე ხშირად მეორდება, ის განზოგადდება მდგრად ფაქტად მომხმარებელზე (ეპიზოდური → სემანტიკური) — ძილისეული კონსოლიდაციის მსგავსად.
  5. იხსენებს არსზე დაფუძნებით, სიახლით შეწონილს — რელევანტურ მომენტში ამოაქვს ყველაზე სასარგებლო მოგონება; გამოყენება მას კვლავ აძლიერებს. S += 0.5
  1. Listens and judges importance — Like a person, it doesn't memorize everything: trivia fades, important things (names, emotions, commitments) stay. salience
  2. Stores the gist, not verbatim — We remember the meaning of a conversation (gist), not exact text; but we keep one exact quote (anchor) for when precision matters.
  3. Forgets gradually over time — A trace weakens unless refreshed; important ones weaken slower. R = exp(−Δt/S)
  4. Consolidates 'offline' — When the same thing recurs, it is generalized into a durable fact about the user (episodic → semantic) — like sleep consolidation.
  5. Recalls gist-first, weighted by freshness — At the relevant moment it brings back the most useful memory; using it strengthens it again. S += 0.5

B — სიტყვასიტყვითი RAG — ინახავს ყველა რეპლიკას ზუსტად, იძახებს top-k მსგავსს.
B+ — კურირებული, სტატიკური (აქტიური კონტროლი) — ინახავს დამუშავებულ gist-ს, decay/salience/კონსოლიდაციის გარეშე.
C — Profile C — სრული ადამიანისებრი დინამიკა (ხუთივე მექანიზმი).
A — No memory — only the last turns of the current conversation (baseline).
B — Verbatim RAG — stores every turn exactly, retrieves the top-k similar.
B+ — Curated, static (active control) — stores a processed gist, without decay/salience/consolidation.
C — Profile C — full human-like dynamics (all five mechanisms).

მთავარი კონტრასტი: C vs B+. ორივეს აქვს „დასუფთავებული“ (gist) მეხსიერება; მხოლოდ C-ს აქვს დინამიკა (დაქვეითება, salience, კონსოლიდაცია). ამიტომ თუ C იგებს, ეფექტი დინამიკიდან მოდის და არა უბრალოდ კურაციიდან. ნახაზები 1–3 ამ სურათს ასახავენ (1 — ციკლი, 2 — დაქვეითების მრუდი, 3 — ოთხი პირობა).

The key contrast: C vs B+. Both have 'cleaned' (gist) memory; only C has the dynamics (decay, salience, consolidation). So if C wins, the effect comes from the dynamics, not merely curation. Figures 1–3 depict this (1 — the cycle, 2 — the decay curve, 3 — the four conditions).

Formulas & mechanisms

R = exp(−Δt / S)

ებინგჰაუსის დავიწყების მრუდი — კვალის მოძიებადობა ეცემა დროსთან ერთად.

Ebbinghaus forgetting curve — a trace's retrievability falls with time.

  • R — მოძიებადობა (retrievability), 0–1 — კვალის მიმდინარე სიძლიერე.
  • Δt — გასული დრო სესიის ერთეულებში (now − last).
  • S — მდგრადობა (stability) — რაც დიდია, მით ნელა ქრება კვალი.
  • R — retrievability, 0–1 — a trace's current strength.
  • Δt — elapsed time in session units (now − last).
  • S — stability — the larger it is, the slower the trace decays.

უარყოფითი ნიშანი: დროის ზრდასთან ერთად Δt იზრდება და R მონოტონურად ეცემა; დიდი S ნელ ქრობას ნიშნავს. გამყარების გარეშე R ვერ გაიზრდება.

Negative sign: as time grows, Δt increases and R falls monotonically; a large S means slow decay. Without reinforcement R cannot rise.

ნახაზი 4 — საბაზისო და საკონტროლო პირობები (MemA, MemB, MemB+)

სამი მარტივი კლასი, რომლებთანაც Profile C შედარდება.

  • MemA — გრძელვადიანი მეხსიერების გარეშე: end_session არაფერს აკეთებს, retrieve აბრუნებს ცარიელს. მუშაობს მხოლოდ საერთო სამუშაო ფანჯარა (ბოლო 6 რეპლიკა). „ამნეზიური“ ბაზისი.
  • MemB — სიტყვასიტყვითი RAG: სესიის ბოლოს ინახავს ყოველ რეპლიკას ზუსტად + მის embedding-ს; მოძიებისას query-ს embed-ავს, ალაგებს კოსინუსური მსგავსებით და აბრუნებს top-K-ს (4) verbatim.
  • MemBplus — კურირებული, სტატიკური (აქტიური კონტროლი): იგივე B, ოღონდ შენახვამდე ყოველ მოვლენას ამცირებს gist-ად (_gist(ev)); მოძიება იდენტურია. decay-ის, salience-ის, კონსოლიდაციის გარეშე.

მთავარი → B და B+ განსხვავდებიან მხოლოდ ერთი ხაზით — ev (ნედლი) vs _gist(ev) (დამუშავებული). დანარჩენი იდენტურია — სწორედ ეს იზოლირებს „კურაცია vs დინამიკა“-ს.

Figure 4 — Baseline and control conditions (MemA, MemB, MemB+)

Three simple classes that Profile C is compared against.

  • MemA — no long-term memory: end_session does nothing, retrieve returns empty. Only the shared working window (last 6 turns) works. The 'amnesiac' baseline.
  • MemB — verbatim RAG: at session end stores each turn exactly + its embedding; on retrieval embeds the query, sorts by cosine similarity, returns the top-K (4) verbatim.
  • MemBplus — curated, static (active control): same as B, but before storing it reduces each event to a gist (_gist(ev)); retrieval is identical. Without decay, salience, or consolidation.

Key → B and B+ differ by a single line — ev (raw) vs _gist(ev) (processed). Everything else is identical — this is exactly what isolates 'curation vs dynamics'.

ნახაზი 5 — Profile C: კოდირება და კონსოლიდაცია

როგორ ჩაიწერება მოგონება და როგორ იბადება მისგან ცოდნა.

  • ორი საცავი: episodes (კონკრეტული მოვლენა — gist, anchor, embedding, სტაბილურობა S, ბოლო ნახვა, salience) და semantic (მდგრადი ფაქტი — fact, embedding, S, last, წყარო-ეპიზოდები).
  • end_session: ერთი LLM გამოძახება (_salience_batch) აფასებს ყველა მოვლენის მნიშვნელობას 0–1. თითოზე ითვლება gist+anchor და საწყისი სტაბილურობა S0 = DECAY_S_BASE · max(0.1, sal) → მნიშვნელოვანი ნელა ქრება, ტრივია სწრაფად.
  • _consolidate: ეპიზოდებს აჯგუფებს embedding-მსგავსებით (cos > 0.55); თუ მტევანში ≥2 ეპიზოდია → აბსტრაჰირდება ერთ სემანტიკურ ფაქტად (_semantic_fact).
  • დუბლიკატის თავიდან აცილება: ფაქტი ინახება მხოლოდ თუ ყველა არსებულთან cos < 0.8; მდგრადობა მაღალია — S = DECAY_S_BASE · 2.5 = 5.0; ინახება back-pointer-ებიც (src) წყარო-ეპიზოდებზე.

მთავარი → სტაბილურობა salience-ს მიჰყვება (S0), და განმეორება ბადებს ცოდნას (ეპიზოდური → სემანტიკური). ეს CLS-ისა და ჰიპოკამპური ინდექსირების პრაქტიკული იმპლემენტაციაა.

Figure 5 — Profile C: encoding and consolidation

How a memory is written and how knowledge is born from it.

  • Two stores: episodes (a specific event — gist, anchor, embedding, stability S, last-seen, salience) and semantic (a durable fact — fact, embedding, S, last, source episodes).
  • end_session: one LLM call (_salience_batch) rates every event's importance 0–1. For each, gist+anchor and initial stability S0 = DECAY_S_BASE · max(0.1, sal) are computed → important decays slowly, trivia fast.
  • _consolidate: clusters episodes by embedding similarity (cos > 0.55); if a cluster has ≥2 episodes → abstract into one semantic fact (_semantic_fact).
  • Duplicate avoidance: a fact is stored only if cos < 0.8 to all existing ones; stability is high — S = DECAY_S_BASE · 2.5 = 5.0; back-pointers (src) to source episodes are kept too.

Key → Stability follows salience (S0), and repetition breeds knowledge (episodic → semantic). This is the practical implementation of CLS and hippocampal indexing.

ნახაზი 6 — Profile C: მოძიება (decay-შეწონილი, gist-first)

როგორ ამოირჩევა, რა გაიხსენოს მოცემულ რეპლიკაზე.

  • _R(m, now): მოძიებადობა = exp(−Δt / S), სადაც Δt = now − ბოლო ნახვა (S ≥ 0.3). ებინგჰაუსის დაქვეითება ითვლება „ზარმაცად“ — მხოლოდ მოძიების მომენტში, არა ფონურად.
  • ყოველ სემანტიკურ ფაქტზე: თუ R < FORGET_FLOOR (0.10) → გამოტოვება („დავიწყებული“); თუ არა → ქულა = cos × R × 1.25 (სემანტიკური ბონუსი).
  • ყოველ ეპიზოდზე იგივე, ოღონდ ბონუსის გარეშე (cos × R). შემდეგ ალაგებს ქულით და იღებს top-K-ს (4).
  • გამყარება: დაბრუნებულ ყოველ მოგონებაზე S += 0.5 და last = now → გამოყენება აძლიერებს კვალს და „ანულებს საათს“ (spacing effect).

მთავარი → ორი ძალა ერთდროულად წყვეტს რა გაიხსენოს — მსგავსება (რამდენად რელევანტურია) × სიახლე (R, რამდენად ცოცხალია); ფაქტებს მცირე უპირატესობა (×1.25).

Figure 6 — Profile C: retrieval (decay-weighted, gist-first)

How the system picks what to recall for a given turn.

  • _R(m, now): retrievability = exp(−Δt / S), where Δt = now − last-seen (S ≥ 0.3). Ebbinghaus decay is computed 'lazily' — only at retrieval time, not in the background.
  • For each semantic fact: if R < FORGET_FLOOR (0.10) → skip ('forgotten'); else score = cos × R × 1.25 (semantic bonus).
  • For each episode the same, but without the bonus (cos × R). Then sort by score and take the top-K (4).
  • Reinforcement: for each returned memory S += 0.5 and last = now → use strengthens the trace and 'resets its clock' (spacing effect).

Key → Two forces decide what to recall — similarity (how relevant) × freshness (R, how alive); facts get a small edge (×1.25).

Memory-strength dynamics

მოძიებადობა R = exp(−Δt/S)retrievability R

კვალის მიმდინარე სიძლიერე 0–1: R = exp(−Δt / S), სადაც Δt არის ბოლო წვდომიდან გასული დრო, S — სტაბილურობა. ითვლება „ზარმაცად“, მხოლოდ მოძიების მომენტში, არა ფონურად.

↗ Ebbinghaus 1885

retrievability Rმოძიებადობა R = exp(−Δt/S)

A trace's current strength 0–1: R = exp(−Δt / S), where Δt is time since last access and S is stability. Computed 'lazily', only at retrieval time, not in the background.

↗ Ebbinghaus 1885

დაქვეითებაdecay

ებინგჰაუზისეული ექსპონენციალური შენელება: გაუმეორებელი კვალი დროსთან ერთად ქრება. ვიღებთ როგორც ინჟინერიულად სასარგებლო ფორმას — და არა კოგნიტური სიზუსტის პრეტენზიას.

↗ Ebbinghaus 1885

decayდაქვეითება

Ebbinghausian exponential decline: an unrehearsed trace fades over time. Adopted as an engineering-useful form — not a claim of cognitive fidelity.

↗ Ebbinghaus 1885

სტაბილურობა Sstability S

განსაზღვრავს, რამდენ ხანს ძლებს კვალი. საწყისი მნიშვნელობა salience-ს მიჰყვება (S₀ = 2.0 · max(0.1, salience)); სემანტიკური ფაქტი გაცილებით მდგრადია (S = 5.0). დიდი S ნელ დაქვეითებას ნიშნავს.

stability Sსტაბილურობა S

Determines how long a trace lasts. The initial value follows salience (S₀ = 2.0 · max(0.1, salience)); a semantic fact is far more durable (S = 5.0). Large S means slow decay.

დავიწყების ზღვარი — FORGET_FLOOR (0.10)forgetting floor — FORGET_FLOOR (0.10)

თუ კვალის მოძიებადობა R < 0.10, ის მოძიებისას გამოტოვდება („რბილი დავიწყება“) — არ იშლება, არამედ დროებით მიუწვდომელი ხდება, ძლიერ მინიშნებაზე აღდგენადი.

forgetting floor — FORGET_FLOOR (0.10)დავიწყების ზღვარი — FORGET_FLOOR (0.10)

If a trace's retrievability R < 0.10 it is skipped at retrieval ('soft forgetting') — not deleted, just temporarily inaccessible, recoverable on a strong cue.

სემანტიკური ბონუსი — SEM_BONUS (×1.25)semantic priority — SEM_BONUS (×1.25)

მოძიების ქულაში სემანტიკური (განზოგადებული) ფაქტების უპირატესობა ეპიზოდებთან შედარებით — მათი ქულა მრავლდება 1.25-ზე.

semantic priority — SEM_BONUS (×1.25)სემანტიკური ბონუსი — SEM_BONUS (×1.25)

In the retrieval score, a preference for semantic (generalized) facts over episodes — their score is multiplied by 1.25.

მნიშვნელობით რეგულირებული კოდირებაsalience-gating

ერთ LLM-გამოძახებაში ფასდება ყოველი მოვლენის მნიშვნელობა (0–1); ეს განსაზღვრავს საწყის სტაბილურობას. მნიშვნელოვანი (სახელები, ემოციები, ვალდებულებები) დიდხანს ძლებს, ტრივია სწრაფად ქრება.

salience-gatingმნიშვნელობით რეგულირებული კოდირება

In one LLM call each event's importance is rated (0–1); this sets its initial stability. Important items (names, emotions, commitments) persist; trivia fades fast.

გამყარება (S += 0.5)reinforcement (S += 0.5)

მოძიებული კვალის სტაბილურობა იზრდება (S += 0.5) და „საათი ნულდება“ (last = now). გამოყენება აძლიერებს მეხსიერებას — ინტერვალური გამეორების (spaced repetition) ეფექტი.

reinforcement (S += 0.5)გამყარება (S += 0.5)

A retrieved trace's stability increases (S += 0.5) and its 'clock resets' (last = now). Using a memory strengthens it — the spaced-repetition effect.

ცივი დაწყებაcold-start

სესიის დასაწყისში მეხსიერება ცარიელი ან სუსტია; Profile C-ს კონსოლიდაცია ნელა გროვდება, ამიტომ მისი ეფექტი მხოლოდ გვიან, პოსტ-კონსოლიდაციურ ფანჯარაში ვლინდება — რასაც ანალიზი ითვალისწინებს.

cold-startცივი დაწყება

At the start of a session memory is empty or weak; Profile C's consolidation accumulates slowly, so its effect shows only in the late, post-consolidation window — which the analysis accounts for.

Q1Operationalization

You operationalize the 'assistant' vs 'interlocutor' distinction via three measurable properties — in exactly what units and with what instrument is each measured? Where is the boundary? Isn't the definition circular — build the system first, then fit the concept to its properties?

Q2Statistical power

Q3Choice of theories

Why exactly these theories and not ACT-R, CLS, or Baddeley's working memory? The Ebbinghaus curve is from 1885, on nonsense syllables, one subject — on what basis carry it over to dialogue?

(1) Three explicit selection criteria: (a) a published LLM-implementation precedent (Ebbinghaus→MemoryBank, segmentation→EM-LLM, gist→ReadAgent, hippocampal→HippoRAG); (b) a user-observable behavioral signature; (c) computability within a voice latency budget. (2) On exclusions: the ACT-R-like score in Generative Agents is the authors' own design ('ACT-R-like', not grounded); CLS is reflected in the consolidation design; working memory is an intra-session concern. (3) On Ebbinghaus: no cognitive fidelity is claimed — the curve is an engineering-useful form of decay (MemoryBank precedent); the testable variable is perception, not psychological accuracy.

A/B/C არის განზრახ, სიმძლავრით შეზღუდული პირველი ჭრილი: ჯერ უფრო ფუნდამენტური კონტრასტი (ათეორიული verbatim B vs თეორიული C vs უმეხსიერო A); n≈20 ვერ დაიტევს 6 თეორიულ მკლავს (F12). სრული თეორია-თეორიის ფაქტორიალი = სამომავლო კვლევა. ეს გულახდილად უნდა ითქვას მეთოდებში.
Q15Gap vs design mismatch

The gap = 'theories have not been compared to each other', but your A/B/C compares three memory modes, not theories to each other. A mismatch?

A literature gap (a field-level omission) ≠ the scope of the thesis's first step. A/B/C is a deliberate, power-limited first cut: first the more fundamental contrast (atheoretical verbatim B vs theoretical C vs memoryless A); n≈20 can't hold 6 theoretical arms. The full theory-by-theory factorial = future work. This must be stated honestly in the methods.

Q16THE killer question: კურაცია vs დინამიკა

ჩაატარეთ დამატებითი offline LLM-პასები C-ის მეხსიერების gist-ისთვის. თუ C იგებს, საიდან იცით, რომ ეს ადამიანური დინამიკაა და არა უბრალოდ ის, რომ მეორე LLM-მა კონტექსტი უფრო წაკითხვადად აქცია?

ამიტომ არსებობს B+ აქტიური კონტროლი — იგივე offline gisting/cleanup, იგივე კომპრესია/ბიუჯეტი, მაგრამ დაყოვნების, salience-ის, კონსოლიდაციის გარეშე. C > B+ ⟹ ეფექტი დინამიკაა; C ≈ B+ ⟹ კურაცია იყო და მტკიცება გულახდილად გადაიხედება. ეს არის დიზაინის ცენტრალური მეთოდოლოგიური სვლა.
Q16Curation vs dynamics (THE killer question)

You ran extra offline LLM passes for C's memory gist. If C wins, how do you know it's human-like dynamics and not simply that a second LLM made the context more readable?

That is exactly why the B+ active control exists — the same offline gisting/cleanup, the same compression/budget, but without decay, salience, or consolidation. C > B+ ⟹ the effect is dynamics; C ≈ B+ ⟹ it was curation and the claim is honestly revised. This is the central methodological move.
Q17C უბრალოდ B მეტი რესურსით ხომ არ არის?
inference-ზე A/B/B+/C იზიარებს ერთსა და იმავე LLM-ს, retrieval trigger-ს, injection point-ს, per-turn ლატენტურობას, token-ბიუჯეტს; per-event payload ≤ B-ის per-turn; sync გზა read-only, ნულოვანი in-turn LLM call. C შერჩევით ინახავს (soft-discard), არა მეტს. ყველა ძვირი ოპერაცია offline-ია.
Q17Isn't C just B with more resources?
At inference A/B/B+/C share the same LLM, retrieval trigger, injection point, per-turn latency, token budget; the per-event payload ≤ B's per-turn; the sync path is read-only, zero in-turn LLM calls. C stores selectively (soft-discard), not more. All expensive operations are offline.
Q18decay-ის მასშტაბი study-window-ზე reverse-engineered ხომ არ არის?
decay-კონსტანტები გარედანაა anchored (MemoryBank [6]); სავალდებულოა (ა) sensitivity analysis (S_base ½×/2×, α, ε, power-law ვარიანტი) და (ბ) a-priori power analysis რომელიც decay-ის timescale-ს study-ხანგრძლივობას უკავშირებს — ნული არ იქნება უბრალოდ cold-start.
Q18Is decay's scale reverse-engineered from the study window?
Decay constants are anchored externally (MemoryBank [6]); mandatory: (a) a sensitivity analysis (S_base ½×/2×, α, ε, a power-law variant) and (b) an a-priori power analysis linking the decay timescale to study duration — the null won't be mere cold-start.
Q19Ebbinghaus 1885, ერთი სუბიექტი; power-law უკეთ ერგება. რატომ ექსპონენტა?
კოგნიტიურ ერთგულებას ვუარყოფთ (ლიტ. მიმოხილვა). ვიღებთ graceful, დროით-და-salience-დამოკიდებულ decay-ს როგორც ინჟინერიულ ფორმას, რომლის აღქმითი ეფექტიც იზომება — MemoryBank-ის [6] პრეცედენტით. power-law წინასწარ რეგისტრირებულია sensitivity-ვარიანტად.
Q19Ebbinghaus 1885, one subject; a power-law fits better. Why an exponential?
We reject cognitive fidelity (Literature Review). We adopt graceful, time-and-salience-dependent decay as an engineering form whose perceptual effect is measured — with MemoryBank's [6] precedent. The power-law is pre-registered as a sensitivity variant.
Q20C-ის დავიწყება ხან ნულოვან ჩანაწერს ნიშნავს. რატომ არის ეს „თბილი" დავიწყება და არა „ცივი" უგულისყურობა?
C არ შლის hard-ად — soft-discard: ძალიან დაბალი stability-ით ჩაწერა, „ენის წვერზე" კვალი, ძლიერ მინიშნებაზე აღდგენადი. მომხმარებელი ლიტერალურ ცარიელ ადგილს ვერ წააწყდება. warm-vs-cold განსხვავება წინასწარ რეგისტრირებული პროგნოზია.
Q20C's forgetting can mean a null record. Why 'warm' forgetting, not 'cold' neglect?
C does not hard-delete — it soft-discards: written with very low stability, a 'tip-of-the-tongue' trace, recoverable on a strong cue. The user never hits a literal blank. The warm-vs-cold difference is a pre-registered prediction.
Q21within-subject + stateful მეხსიერება = carryover. B ფაზა აბინძურებს C-ს. როგორ გამორიცხავთ?
თითო პირობას იზოლირებული store; counterbalanced რიგი; washout; წინასწარ რეგისტრირებული order-effect/carryover ტესტი; between-subjects მკლავის განხილვა.
Q21within-subject + stateful memory = carryover. Phase B contaminates C. How do you rule it out?
An isolated store per condition; counterbalanced order; washout; a pre-registered order-effect/carryover test; consideration of a between-subjects arm.
Q22რით განსხვავდება MemoryBank-ისა და Generative Agents-ისგან?
MemoryBank [6] = მხოლოდ Ebbinghaus verbatim-ზე (gist/სეგმენტაცია/კონსოლიდაცია არ აქვს). Generative Agents [10] = recency×importance×relevance, ავტორების მიხედვით არა theory-grounded (F6). C აერთიანებს ხუთივე თეორიას ერთ lifecycle-ში და პირველად ფასდება აღქმულ სოციალურ კონსტრუქტებზე კურაცია-კონტროლირებული დიზაინით.
Q22How does it differ from MemoryBank and Generative Agents?
MemoryBank [6] = Ebbinghaus over verbatim only (no gist/segmentation/consolidation). Generative Agents [10] = recency×importance×relevance, by the authors' own account not theory-grounded. C composes all five theories into one lifecycle and is the first evaluated on perceived social constructs with a curation-controlled design.
Q23სტატისტიკური სიმძლავრე C>B+-ზე (THE დომინანტური)

თქვენი ცენტრალური სიახლე არის C>B+. n=20-ზე ეს გამოვლენადია?

არა — C>B+ ეფექტი dz≈0.28 (cold-start-ის შემდეგ ~0.14–0.20), გამოვლენადი ზღვარი n=20-ზე ~0.78–0.86; საჭიროა n≈116–159 (შეუძლებელი ამ კლასისთვის). ამიტომ C>B+ წინასწარ რეგისტრირებულია როგორც ESTIMATION მიზანი (საშუალო სხვაობა + 95% CI + dz, precision/equivalence ლოგიკა), არა confirmatory ტესტი. ნაშრომის წვლილია კურაცია-კონტროლირებული აპარატი + ნიშან-აგნოსტიკური გაზომვა. სუფთა ნული პუბლიკაბელურია — B+ კონტროლი სწორედ ამისთვისაა შექმნილი.
Q23Statistical power for C>B+ (THE dominant one)

Your central novelty is C>B+. Is it detectable at n=20?

No — the C>B+ effect is dz≈0.28 (after cold-start ~0.14–0.20), the detectable floor at n=20 is ~0.78–0.86; you'd need n≈116–159 (infeasible for this class). So C>B+ is pre-registered as an ESTIMATION goal (mean difference + 95% CI + dz, precision/equivalence logic), not a confirmatory test. The contribution is the curation-controlled apparatus + sign-agnostic measurement. A clean null is publishable — the B+ control exists exactly for this.
Q24null-ის შემთხვევაში რა გრჩებათ?
სამი დაცვადი ჩარჩო: (1) „legibility ჰიპოთეზა დადასტურდა" — C≈B+ + B+>B აჩვენებს, რომ აღქმული ღირებულება gist-კურაციით და მეხსიერების არსებობით მოდის, არა Ebbinghaus/salience/CLS დინამიკით (აქარწყლებს დარგის დაშვებას); (2) დისოციაციის რუკა (რაოდენობრივი + თვისებრივი); (3) boundary-condition (2–3 კვირა, single-user — კონკრეტული follow-up დღის წესრიგი). aim თავიდანვე ფორმულირებულია როგორც „დინამიკის მარგინალური წვლილის გაზომვა (შესაძლოა ნული)".
Q24What's left in the null case?
Three defensible frames: (1) 'the legibility hypothesis is confirmed' — C≈B+ plus B+>B shows perceived value comes from gist-curation and the mere presence of memory, not from Ebbinghaus/salience/CLS dynamics (refutes a field assumption); (2) a dissociation map (quantitative + qualitative); (3) boundary conditions (2–3 weeks, single-user — a concrete follow-up agenda). The aim is framed from the outset as 'measuring the marginal contribution of the dynamics (possibly null)'.
Q25„თქვენი დავიწყება არ არის ადამიანის დავიწყება"
მართალია — მოდელირებულია სუფთა დროითი decay-ით, გამოტოვებულია ინტერფერენცია (ადამიანის დავიწყების დომინანტური დინამიკა). ვაღიარებთ როგორც შეზღუდვას; decay არის ინჟინერიული ფორმა, არა კოგნიტიური ერთგულება (ლიტ. მიმოხილვა). ინტერფერენცია/temporal-order — სამომავლო კვლევა.
Q25'Your forgetting is not human forgetting'
True — modeled with pure temporal decay, omitting interference (the dominant dynamic of human forgetting). Acknowledged as a limitation; decay is an engineering form, not cognitive fidelity (Literature Review). Interference/temporal-order — future work.
